# NeuralArt
# 🎨 Neural Style Transfer Web Application

A Deep Learning-powered **Neural Style Transfer (NST)** web application built using **Flask** and **PyTorch** that transforms ordinary images into artistic masterpieces by combining the **content of one image** with the **style of another image**.

The application uses a **pre-trained VGG network** and **Adaptive Instance Normalization (AdaIN)** to generate high-quality stylized images while preserving image content.

---

## 🚀 Features

✅ Upload content and style images  
✅ Generate artistic stylized images  
✅ Fast Neural Style Transfer using Deep Learning  
✅ User-friendly web interface with Flask  
✅ Supports multiple image formats  
✅ Real-time image processing in browser

## 🧠 How It Works

1. Upload a **Content Image**
2. Upload a **Style Image**
3. The model extracts:
   - Content features
   - Style features
4. Neural Style Transfer is applied using **AdaIN**
5. A new artistic image is generated and displayed.

## 🧮 Model Architecture

This project uses:

- **VGG Encoder**
- **Decoder Network**
- **Adaptive Instance Normalization (AdaIN)**

### AdaIN Formula

```math
AdaIN(content, style) =
σ(style)
(
(content - μ(content))
/
σ(content)
)
+ μ(style)
```

Where:

- μ = Mean
- σ = Standard Deviation
