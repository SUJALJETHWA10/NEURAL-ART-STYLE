# NeuralAr
# 🎨 Neural Style Transfer using Deep Learning

A Deep Learning-based **Neural Style Transfer (NST)** project that combines the **content of one image** with the **artistic style of another image** to generate visually appealing artwork using Convolutional Neural Networks (CNNs).

This project uses a **pre-trained VGG19 network** to extract image features and apply artistic styles while preserving content structure.

---

## 📌 Features

- Convert ordinary images into artistic paintings
- Apply famous painting styles to images
- Preserve image content while transferring artistic texture
- Uses **VGG19 Pre-trained Model**
- Fast image generation using **PyTorch**
- Customizable style intensity

## 🖼️ How It Works

1. Upload a **Content Image**
2. Upload a **Style Image**
3. The model extracts:
   - **Content Features** from the content image
   - **Style Features** from the style image
4. A new stylized image is generated by blending both representations.

---

## 🧠 Model Architecture

The project uses:

- **VGG19 Encoder**
- Feature Extraction Layers
- Decoder Network
- Adaptive Instance Normalization (AdaIN)

### Formula Used:

```math
AdaIN(content, style) =
\sigma(style)\left(
\frac{content - \mu(content)}
{\sigma(content)}
\right) + \mu(style)
```

Where:

- μ = Mean
- σ = Standard Deviation
